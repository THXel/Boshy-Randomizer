# Changelog

## 1.0.1

- Manually resized and maximized windows retain their size when resetting or changing rooms. Display options still apply when selected.

## 1.0.0 — 2026-11-02

The first release of Boshy Randomizer.

- Five modes: Randomizer, Target Select, Normal, Boss Rush and Level Rush.
- Custom routes, shared seeds, three save slots and mixed item/character rewards.
- Sprite, background, shot and music randomization, plus optional practice settings.
- An in-game target list, LiveTracker and a run summary over the credits.
- Five languages, saved soundpack preferences and 4:3 or stretched 16:9 display.
- Windows Setup and Linux DEB installers using your own original Boshy game.

Original I Wanna Be The Boshy by Solgryn / Grynsoft. Randomizer mod by THXel.
