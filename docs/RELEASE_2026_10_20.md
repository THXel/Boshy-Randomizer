## New in this update

- **Kamilia 3:** a translucent red fade followed by its Game Over title, imported blood sprites and original death audio.
- **WannaFest22:** Game and Over arrive rapidly from opposite sides, with animated VHS noise, the restart prompt, matching blood and death audio.
- Imported death screens no longer inherit Boshy's bouncing scale or delayed visibility. Quick resets clear the imported death cue and presentation.
- **Original reset behavior stays unchanged for all three packs.** No extra reset sound is added.
- Image checksums and animation bounds are validated before activation; Original Boshy restores the native presentation.

Death graphics require an updated **locally supplied** soundpack. Older audio-only packs remain supported. The repository includes a local import utility; extracted game projects and media are never included in the release.

## Verification

Linux/Wine testing includes repeated Q/R cycles, resets during different animation phases, a level and boss room, return to Original, and native no-bounce checks. The Windows installer is rebuilt and checked on a Windows CI runner; this update has not had a new interactive Windows 10 gameplay test. The Windows build remains a preview.
