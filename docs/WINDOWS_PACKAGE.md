# Windows installation

Download **BoshyRandomizer-Setup-1.0.2.exe** from the [1.0.2 release](https://github.com/THXel/Boshy-Randomizer/releases/tag/v1.0.2).

1. Close Boshy Randomizer and open Setup.
2. Choose your original Boshy ZIP or extracted game folder.
3. Follow the progress display. At the end, you can start the game immediately.

Setup creates its own patched copy, a Start menu entry and an uninstaller. Your original game stays separate. Installation is per-user by default and has been tested on Windows 11 x64.

To remove it, use Windows Installed Apps. Saves and preferences are kept unless you explicitly choose to remove them. Do not delete the original game to uninstall the randomizer.

The installer is unsigned. Check its SHA-256 against the release's SHA256SUMS; signing reputation is not established by a checksum.
