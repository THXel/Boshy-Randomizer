# Windows cold-start and package-integrity fixes

This update fixes two issues found while testing a fresh Windows 11 VirtualBox installation.

- **Rebuilt Extras DLLs now pass their runtime integrity check.** The build binds the expected checksum to the DLL it actually produced. Unknown or modified DLLs are still rejected. This packaging fix applies to both Windows and Linux; it replaces the affected 2026.10.20 and 2026.10.20.1 downloads.
- **Windows waits for slow first launches.** The host can wait up to three minutes for the game window while monitoring the launched process. If the process exits, it fails promptly. Linux keeps its existing startup deadline.
- Includes the soundpack death-screen, audio-isolation and gallery improvements from [2026.10.20.1](https://github.com/THXel/Boshy-Randomizer/releases/tag/v2026.10.20.1).

## Downloads

- Windows x64: `BoshyRandomizer-2026.10.20.2-Windows-Setup-x64.exe`
- Linux Mint 22 / Ubuntu 24.04, amd64, X11: `boshy-randomizer_2026.10.20.2-1_amd64.deb`

The original game and optional soundpack media are not included. Existing saves and settings are preserved. Supply your own Boshy folder or ZIP on first launch.

## Validation

The corrected Windows candidate passed installation, first-run game import, native-menu startup, a normal-mode game start and Q/R smoke checks in a fresh Windows 11 VM. Defender and real-time protection stayed enabled. These are startup checks, not a full playthrough of every mode or hack combination. Release builds also run native compilation and regression tests before packaging.
