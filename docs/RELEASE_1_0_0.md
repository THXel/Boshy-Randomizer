# Boshy Randomizer 1.0.0

Rediscover Boshy. A new adventure with every seed.

Shuffle worlds, bosses, chests and sprites. Pick from five modes, build your own route or hunt a Target Select checklist. Share your seed with friends and follow your run in LiveTracker.

## Start playing

1. Download the Windows Setup or Linux DEB below.
2. Select your own original Boshy ZIP or game folder during setup.
3. Choose a save slot, pick a mode and start your run.

The original game is not included. Setup creates a separate, patched game copy.

Windows 11 · Linux Mint 22 / Ubuntu 24.04, amd64, X11.
