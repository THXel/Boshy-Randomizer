# 2026.10.22.1 — live-test repairs

- Windows foreground-focus denial, including PyGetWindow error code zero, no longer aborts startup. Input still requires confirmed focus.
- The Windows loading cover applies non-activating styles to Tk's top-level wrapper after mapping and returns foreground ownership from the cover process itself. This fixes menu-to-game startup when Windows refuses the background controller's focus request.
- Linux no longer interprets a Wine process ID as a Linux process ID.
- Routed exits commit the intercepted native exit before requesting the new destination, preventing an obsolete exit from interfering with the route.
- Actor recoloring uses the live animation bank and reacquires its pointer after the engine can copy it. Per-scene image caches reset on reload, including same-room resets.
- Normal enemy death sounds no longer trigger player death music suppression. Player death matching requires the verified Death 3 action on literal channel 5.
- Original blood animation and actions stay available for enemies. Custom blood uses a separate animation bank and only particles from the player death burst.
- Gameplay setting edits renew the seed once per action, for mouse and keyboard. Explicit seed imports retain their seed until a subsequent edit.
- Advanced selection shows its page number and explains where additional bosses, including Gravitron, are listed.
- Composed submenu labels and stage names translate correctly; missing settings and diagnostic translations were added for German, English, Spanish, Russian and Japanese.
- Closing a broken game bridge cannot replace the original failure with a BrokenPipeError.

Game files, saves, private settings, soundpacks and test recordings are excluded from both installers. This is a local repair build; publication is a separate step.
