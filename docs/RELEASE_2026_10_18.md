## Choose your adventure

- **Randomizer:** shuffled level and boss routes, mixed item/character chest rewards and optional character rotation.
- **Target Select:** collect randomly selected goals and optional boss targets. Original chest contents stay recognizable; routes continue until the goals are complete.
- **Normal:** original progression with optional starting character, character rotation and hacks.
- **Boss Rush / Level Rush:** choose your pool and section count — seven by default — then face Solgryn.

Share compact seeds, keep three independent runs and follow progress in a separate live tracker. Customize shot styles, music, complete backgrounds and optional hacks; enjoy a run summary after the finale. The interface supports English, German, Russian, Spanish and Japanese.

## Install & play

**Windows:** open the setup, follow the wizard and launch Boshy Randomizer from the Start menu. The installer is unsigned, so an unknown-publisher notice may appear. Keep Defender enabled.

**Linux:** open the DEB with your package manager, or install with `sudo apt install ./boshy-randomizer_2026.10.18-1_amd64.deb`. Dependencies are resolved by APT; the first start prepares the verified Wine runner.

Close the game before updating. Your private game and runs are stored separately from the application. Extra Kamilia 3 / WannaFest22 soundpack audio is optional and not bundled.

## Verification & current limits

The native source suite passes **369 tests**. An isolated Linux game check covered startup, reset, game-window focus and resuming the same saved run with no native errors. Windows 10 VM checks with active Defender covered install, update, uninstall, reinstall, shortcuts, import and saved-run resume. Windows remains a preview: Windows 11, non-ASCII account paths, physical 4K and mixed-DPI displays need more testing. These checks do not certify every boss/hack combination.
