# Boshy Randomizer 1.0.2

Switching languages now refreshes the entire Options room, including help text and on/off values. Previously, some text could remain in the language used before the switch.

Includes the window-size fix from 1.0.1. Install over your existing version to keep your saves and settings.

Original I Wanna Be The Boshy by **Solgryn / Grynsoft**. Randomizer mod by **THXel**.
