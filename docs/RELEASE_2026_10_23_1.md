# 2026.10.23.1 — Windows 11 validation and menu presentation

The in-game update summary now follows the selected UI language. German,
Spanish and English use the original text renderer; Russian and Japanese use
the existing Unicode bitmap panel instead of replacing characters with question
marks. The menu music button draws its note directly, avoiding a missing glyph
in Windows Segoe UI. Source changelogs remain in English.

This includes all gameplay, optional soundtrack-category and source-structure
changes from 2026.10.23. No game or optional soundtrack audio is bundled.

A separate Windows 11 VirtualBox test copy verified fresh installation, upgrade,
all three save slots with repeated restarts, continuation of an older frozen run,
and save deletion while the same game process and unmuted audio session remained
active. Existing saved-rule files were hash checked. These controlled tests do
not replace a natural playthrough of every boss or every random seed.

The release workflow rebuilds both packages and verifies the installed Windows
payload. See the [Windows package guide](WINDOWS_PACKAGE.md) and
[Linux package guide](LINUX_PACKAGE.md).
