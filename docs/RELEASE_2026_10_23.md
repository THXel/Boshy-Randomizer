# 2026.10.23 — Gameplay, soundtrack categories and readable source

This release combines the Windows focus recovery, sprite/death-effect fixes,
Castlevania skeleton protection, Sonic/Solgryn fire-effect protection, Kracko
exit recovery and corrected Random World transitions. Save deletion keeps the
existing game's music running beneath the loading screen. Custom-run controls
cover all selectable route entries, including Gravitron and split level sections.
Solgryn remains the final encounter; Gastly requires its native item unlock.

Optional Kamilia 3 and WannaFest22 soundpacks now use separate level and boss
music bags. Avoidances count as bosses. Intro, clear, ending and unverified tracks
are excluded from gameplay shuffle. Existing private packs are recognized by
file hashes; no game or optional soundtrack audio is included in installers.
See [the complete category table](MUSIC_CATEGORIES.md).

Source is arranged by responsibility under `src/`, `assets/`, `tests/` and
`tools/`. The menu entry point delegates process/profile ownership to its
controller and gameplay/result polling to a separate module. Python and
handwritten C use checked formatting. Packaging consumes a verified generated
runtime, while saved rules retain their established module and resource names.

Automated checks cover menu ownership, each custom-run selection, music category
separation across 200 seeds per pack, native sprite/audio hooks, saved-rule
repairs and package boundaries. Earlier controlled Linux/Wine tests covered the
reported fire effects, Castlevania, Kracko/Mario transitions and uninterrupted
save-deletion audio; these are not an all-boss/all-seed natural playthrough.
The release workflow builds and install-checks the Windows installer separately.
