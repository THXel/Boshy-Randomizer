Boshy Randomizerをご紹介

Boshy Randomizerは初の正式版公開に向けて準備中です。これまでプレイテストを行ったのはTHXelだけです。正式版の準備が整い次第、ここでダウンロードを公開します。

わかりやすいゲームメニュー

2列のカテゴリ、適切なアイコン、説明文、マウスとキーボード操作。現在のシードもすぐに確認できます。

セーブデータのプレビュー

再開前に現在地とコレクションを確認。選択がロックされていなければ、入手したキャラクターをF3で選べます。

画面と個人設定

標準4:3と引き伸ばし16:9、F4で全画面、言語と音楽の設定保存。画面の揺れも無効にできます。

まとまりのある背景と音楽

背景をレイヤーや効果と一緒に交換。ステージ曲とボス曲は別々にシャッフルし、サウンドパックはシードに含めません。

ライブトラッカーとエンディング

LiveTrackerはゲームの言語を使用。クレジット上の結果は×で閉じられ、F2で再起動すると消えます。

進行状況がわかるインストール

進捗表示、準備中の中止、完了後の任意起動。元のBoshyのZIPまたはフォルダーを選択します。

新しいRandomizerとBoss RushのランではBomberman、Questionmark、Ridleyは初期状態で無効です。必要に応じて有効にできます。既存のセーブと読み込んだシードの選択は維持されます。

テスト状況と詳細

これまでゲームをプレイテストしたのはTHXelのみです。自動チェックも開発を支えていますが、広範な公開プレイテストはまだ行っていません。初の公開に向けて最終確認を続けています。

メニューを見てみよう

現在のテスト画面から作成した新しいGIFツアーです。メニュー、表示設定、セーブを紹介します。連続したプレイ動画ではなく、スクリーンショットのアニメーションです。

01 / PLAY

5つの遊び方

どんな遊び方がしたい？

  1. 予想外の展開を楽しみたい

    Randomizer

    おなじみのゲームをシャッフル。

    ステージとボスの行き先を変更し、アイテムとキャラクターを共通の宝箱報酬にします。ルートで候補と数を選択。推奨はステージ7つとボス7体を可能な範囲で交互に進み、最後はSolgryn。

  2. 収集目標に挑戦したい

    Target Select

    目標リストと予測不能な旅。

    ランダムな元のアイテム一覧を集めます。目標数と必須ボスは設定可能。行き先は変わりますが報酬は元のままです。全目標達成後にSolgrynへ進みます。

  3. 元のルートを遊びたい

    Normal

    いつものルートに、自分のルール。

    元の進行と宝箱を維持。開始キャラクター、キャラクター変更、ハックを任意で選べます。追加機能は初期状態でオフです。

  4. ボス戦を楽しみたい

    Boss Rush

    すぐにボス戦へ。

    ボス候補と戦う数を選択。標準は7体で、その後にSolgrynが待ちます。

  5. ステージ攻略がしたい

    Level Rush

    ステージを主役に。

    ステージ候補と区間数を選択。標準は7区間で、最後はSolgryn戦です。

通常ルートの、その先へ

分割ステージ、ミニボス、隠しルートに加え、Ridley、Questionmark、Bomberman、Old Sonicなどのベータ戦も選べます。遷移は画面のピクセルではなくゲームの状態を読み取ります。

アイテムもキャラクターも

宝箱の元の種類に関係なく、アイテムかキャラクターが手に入ります。任意のキャラクター変更では新しく集めたキャラクターも候補に追加。変更機能が有効な間はF3の手動選択をロックします。

#

共有できるシード

短いコードにシードとラン設定をまとめます。ゲーム内でコピー、貼り付け、検証、プレビュー、新規生成が可能。同じランを比較する場合は同じバージョンを使ってください。

III

3スロット、3つの冒険

ランとキャラクター解放をスロットごとに保存。場所、難易度、使用キャラクター、進捗を表示し、ゲーム内メニューから続行・作成・削除できます。

◷

ゲームの横にトラッカー

メインメニューからブラウザーでLiveTrackerを開けます。ゲームの言語を引き継ぎ、時間、死亡数、現在地、入手アイテムとキャラクターを表示します。OBSでも使用できます。

★

最後まで楽しめる結果画面

Solgryn後、少し待って半透明の結果画面を表示。統計とコピー可能なシードを確認しながら、死亡演出とクレジットは背後で続きます。

NEW LOOK · SAME BOSHY

いつものゲームに、新しい景色

背景は対応するレイヤーやエフェクトと一緒にグループ単位で入れ替わります。装飾、足場、敵の色は別々に設定でき、重要なゲーム効果は保護されます。

弾も、音も、新しく。

キャラクターとは独立して弾と発射エフェクトを変更。区間ごと、死亡ごと、両方、または設定時間内のランダムなタイミングを選べます。秒・分で設定でき、標準は5分です。

ステージ曲はステージへ、ボス曲はボスへ、別々の候補から割り当てます。任意でローカルから取り込むKamilia 3とWannaFest22のパックでは音楽とエフェクトも追加できます。追加パックはダウンロードに含まれません。

インストールの流れ

初の正式版には、元のBoshyのZIPまたはゲームフォルダーが必要です。元のゲーム本体は同梱されません。

Windows

  1. インストール

    Windows Setupをダウンロードして開き、ウィザードに従ってBoshy Randomizerをインストールします。

  2. 元のゲームを選択

    セットアップウィザードで元のBoshyのZIPまたはフォルダーを選択します。Randomizer専用のゲームコピーが作成されます。

  3. プレイ

    3つのセーブスロットから1つとモードを選び、ランを開始します。

Linux

  1. DEBのインストール

    パッケージインストーラーでDEBを開き、WineとLutrisを含む依存パッケージと一緒にインストールします。

  2. 初回設定

    アプリケーションメニューからBoshy Randomizerを開きます。Wineの初回設定が終わったら、元のBoshyのフォルダーまたはZIPを選択します。

  3. プレイ

    セーブスロットとモードを選択します。次回からもアプリケーションメニューから起動できます。

専用のゲームコピーを作成するため、元のセーブには触れません。更新・アンインストール後もランのデータは残ります。

いつダウンロードできますか？

初の正式版を準備中です。完成後、WindowsインストーラーとLinux DEBをここで公開します。公開日はまだ決まっていません。

オンラインで遊べますか？

シングルプレイヤー用です。元のオンラインメニューは無効です。友達とシードを共有して同じ条件のランを楽しめます。
