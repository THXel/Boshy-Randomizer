インストールの流れ

初の正式版には、元のBoshyのZIPまたはゲームフォルダーが必要です。元のゲーム本体は同梱されません。

Windows

  1. インストール

    Windows Setupをダウンロードして開き、ウィザードに従ってBoshy Randomizerをインストールします。

  2. 元のゲームを選択

    セットアップウィザードで元のBoshyのZIPまたはフォルダーを選択します。Randomizer専用のゲームコピーが作成されます。

  3. プレイ

    3つのセーブスロットから1つとモードを選び、ランを開始します。

Linux

  1. DEBのインストール

    パッケージインストーラーでDEBを開き、WineとLutrisを含む依存パッケージと一緒にインストールします。

  2. 初回設定

    アプリケーションメニューからBoshy Randomizerを開きます。Wineの初回設定が終わったら、元のBoshyのフォルダーまたはZIPを選択します。

  3. プレイ

    セーブスロットとモードを選択します。次回からもアプリケーションメニューから起動できます。

ランダマイザーは専用のゲームコピーを作成します。元のゲームとセーブデータは別に保たれます。

06 / SUPPORT

知っておきたいこと

配信にも使えますか？

はい。ゲームメニューから内蔵LiveTrackerを開き、ブラウザーやOBSのブラウザーソースで使えます。

遷移がおかしいときは？

ゲームメニューの診断を開き、モード、シード、問題の説明をGitHubの報告に添えてください。

誰がテストしていますか？

これまでのプレイテストはTHXelのみが行っています。初の正式版に向けて最終テスト中です。

いつダウンロードできますか？

初の正式版を準備中です。完成後、WindowsインストーラーとLinux DEBをここで公開します。公開日はまだ決まっていません。

オンラインで遊べますか？

シングルプレイヤー用です。元のオンラインメニューは無効です。友達とシードを共有して同じ条件のランを楽しめます。
