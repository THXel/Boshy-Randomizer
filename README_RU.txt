О ПРОЕКТЕ:
--------------------------------------------------------------
Boshy Randomizer — это фанатский инструмент для игры
"I Wanna Be The Boshy" от Solgryn.

Он случайным образом перемешивает уровни, боссов, предметы,
цели и персонажей, а также добавляет автоматические триггеры,
оверлеи, статистику, систему сидов и другие функции удобства.

Разработка — THXel в сотрудничестве с сообществом
Boshy Speedrun Community.

⚠️ Важно:
Это НЕ оригинальная игра — только инструмент-рандомайзер.
Игровые файлы необходимо добавить вручную (см. ниже).

ТРЕБОВАНИЯ:
--------------------------------------------------------------
• Windows 10 или новее  
• Доступ к интернету (для автоматической установки при первом запуске)


--------------------------------------------------------------
УСТАНОВКА И ЗАПУСК:
--------------------------------------------------------------
1️⃣ Скачайте оригинальную игру "I Wanna Be The Boshy" по ссылке:  
    https://grynsoft.com/old-games

2️⃣ Запустите установщик Boshy Randomizer.  
    После установки появится файл **Boshy Randomizer.exe**.

3️⃣ Запускайте рандомайзер именно через **Boshy Randomizer.exe**.

    Лаунчер автоматически проверит:
    • наличие игры  
    • установку Python и необходимых модулей  
    • наличие всех файлов рандомайзера  

4️⃣ Если игра отсутствует, появится окно выбора ZIP-архива.
    Укажите файл оригинальной игры — он будет автоматически распакован
    в папку /IWBTB.


--------------------------------------------------------------
ИНФОРМАЦИЯ О ГЕЙМПЛЕЕ
--------------------------------------------------------------

• Каждый забег всегда начинается с **Tutorial**.  
  После этого — в зависимости от настроек — генерируется случайный
  маршрут или запускается Target Collect Mode.

• По умолчанию выбран персонаж **Dark Boshy**.  
  Включение «Random Character» выбирает случайного персонажа
  (возможно переключение после каждого уровня/босса).

• **Важно:**  
  Если активирован режим Random Character, меню выбора персонажа (F3)
  **полностью заблокировано**, чтобы сид оставался валидным.

• При первом запуске появляется окно с подсказками:
      – Нажимайте **Ctrl + R** несколько раз для начала нового забега  
      – Используется только **SaveFile1**  
      – SaveFile2 и SaveFile3 отключены  
      – Закрытие игры завершает текущий забег  

• Достижения, коллекционные предметы и открываемые персонажи сохраняются
  на протяжении всего забега.

• Live Tracker автоматически отображает:
      – достижения  
      – коллекционные предметы  
      – боссов  
      – персонажей  
      – цели набора (в Target Mode)  

  Также появляются небольшие всплывающие уведомления при нахождении новых предметов.

⚠️ **Замечание о синхронизации:**  
   Значения (предметы, статистика, смерти боссов, цели) могут обновляться
   с небольшой задержкой — обычно 0.3–1 секунды.

• В Target Collect Mode:
      – маршрут выключен  
      – активируются все опциональные уровни  
      – Gastly и Cheetahman включаются принудительно  
      – необходимо собрать заданное количество целей  
      – после выполнения всех целей автоматически запускается Solgryn  
        как финальный босс

СИСТЕМА СИДОВ
--------------------------------------------------------------
Рандомайзер поддерживает полную систему сидов:

• Вы можете вручную ввести сид в GUI  
• Или позволить инструменту создать новый автоматически  

Сид определяет:
      – полный маршрут по уровням и боссам  
      – порядок персонажей (если включено)  
      – цели в Target Collect Mode  

Сиды можно передавать другим игрокам — они получат **точно такой же забег**.

Сид отображается:
      – в reset-overlay  
      – во время загрузки уровней  
      – в финальном экране после забега  
      – в debug-логе

ТЕХНИЧЕСКИЕ СВЕДЕНИЯ:
--------------------------------------------------------------
• Написано на Python 3.11  
• Используемые библиотеки:
  tkinter, pillow, numpy, pygetwindow, pyautogui  

• Автоматическое логирование:
  **INI/randomizer_debug.log**

При сообщениях об ошибках **обязательно прикладывайте debug-лог**,  
без него невозможно определить проблему.
