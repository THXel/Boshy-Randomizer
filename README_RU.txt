Современный рандомайзер для «I Wanna Be The Boshy»
Случайные маршруты • Live-трекер • Сид-система • Удобный интерфейс

--------------------------------------------------------------
ОСОБЕННОСТИ
--------------------------------------------------------------
• Случайный порядок уровней и боссов
• Надёжная обработка предметов и коллектаблов
• Случайные персонажи — при старте или на каждом этапе
• Target Collect Mode — сбор всех целей, скрытый маршрут
• Live Tracker — достижения, предметы, боссы, персонажи
• Статистика в конце забега + код маршрута
• Детерминированные сиды — полная воспроизводимость забегов
• Автоматическая установка — Python, модули, шрифт, импорт игры

--------------------------------------------------------------
ТРЕБОВАНИЯ
--------------------------------------------------------------
• Windows 10 или новее  
• Подключение к интернету при первой установке  
• Легальная копия «I Wanna Be The Boshy» (ZIP с сайта Grynsoft)

--------------------------------------------------------------
СКАЧИВАНИЕ И УСТАНОВКА
--------------------------------------------------------------

Скачать ZIP:
https://github.com/THXel/Boshy-Randomizer/archive/refs/heads/Boshy-Randomizer.zip

1) Скачайте ZIP-архив по ссылке выше.

2) Распакуйте архив в любое удобное место, например:
   C:\Games\Boshy Randomizer\

   После распаковки структура должна выглядеть так:

      Boshy Randomizer/
       ├─ Custom/
       ├─ INI/
       ├─ PY/
       ├─ Installer Files...
       └─ Boshy Randomizer Installer.exe

3) Запустите установщик:
   Boshy Randomizer Installer.exe

   Установщик автоматически выполнит:
   • копирование всех файлов рандомайзера
   • установку Python 3.x (если отсутствует)
   • установку необходимых модулей
   • установку шрифта «its-boshy-time»
   • запрос вашего ZIP-файла IWBTB
   • распаковку игры в папку /IWBTB
   • создание ярлыков в меню «Пуск»

4) Запуск рандомайзера:
   Пуск → Boshy Randomizer

   При старте лаунчер проверяет:
   • корректный импорт IWBTB  
   • наличие Python  
   • наличие всех модулей  
   • целостность файлов рандомайзера  

   При ошибках будет показано диагностическое сообщение.

--------------------------------------------------------------
ГЕЙМПЛЕЙ И РЕЖИМЫ
--------------------------------------------------------------

НАЧАЛО ЗАБЕГА
• Каждый забег начинается с Туториала.  
• Далее — в зависимости от настроек GUI:
  – Случайный маршрут  
  – Target Collect Mode  

СЛУЧАЙНЫЙ ПЕРСОНАЖ
• Персонаж по умолчанию: Dark Boshy  
• Опционально:
  – случайный при старте  
  – случайный на каждом уровне  
• При активном Random Character меню F3 отключено.

--------------------------------------------------------------
TARGET COLLECT MODE
--------------------------------------------------------------

• Панель маршрута скрыта.  
• Активируются все необходимые опциональные уровни.  
• Цели выбираются на основе сида.  
• После сбора всех целей автоматически появляется Solgryn.

ВАЖНО:
Выключать можно ТОЛЬКО следующие опциональные уровни:
• Boberman  
• Questionmark (?)  
• Ridley  

Все остальные уровни должны быть включены,  
иначе некоторые предметы будет невозможно получить.

--------------------------------------------------------------
ПОВЕДЕНИЕ СИСТЕМЫ
--------------------------------------------------------------

• Используется только SaveFile1.  
• НЕ удаляйте SaveFile1.  
• SaveFile2 и SaveFile3 всегда перезаписываются.  
• Достижения сохраняются на весь забег.  
• Телепорт-комната работает как обычно, но:
  Для продвижения по маршруту необходимо
  проходить уровни, назначенные рандомайзером.
  Пропустить этап через телепорт невозможно.

--------------------------------------------------------------
СИД-СИСТЕМА
--------------------------------------------------------------

Сид определяет:
• порядок уровней и боссов  
• структуру маршрута  
• RNG персонажей (опционально)  
• цели в Target Mode  

Сид отображается:
• при загрузке  
• при старте забега  
• на финальном экране  
• в debug-логе  

Сидами можно делиться для повторения идентичных забегов.
