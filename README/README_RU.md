## 🟦 Функции

- 🎲 **Случайные маршруты** — полностью детерминированные маршруты уровней и боссов  
- 🧩 **Item Randomizer (Безопасный режим статистики)** — *собранные персонажи рандомизируются*, игровые предметы не заменяются (во избежание вылета игры)  
- 🧍 **Character Randomizer** — случайный в начале забега или на каждом уровне, полностью детерминированный  
- 🎯 **Target Collect Mode** — скрытый маршрут, цели зависят от seed  
- 📊 **Лайв‑трекер** — отслеживает предметы, боссов, достижения, персонажей и целевые предметы  
- 🔁 **Детерминированные seeds** — можно поделиться и полностью воспроизвести забег  
- 🧱 **ER/EB маски** — выбор опциональных уровней и боссов сохраняется внутри seed‑кода  
- 🔒 **Seed‑Lock GUI** — ввод seed блокирует GUI и отображает настройки  
- ⚙️ **Автонастройка** — автоматическая установка Python, модулей, шрифтов и импорт IWBTB

### ▶ Шаг 1 — Запустить установщик

**`Boshy Randomizer Installer.exe`**

⚠️ **SmartScreen предупреждение:**  
Windows может показать:

«Windows защитил ваш ПК» / «Неизвестное приложение».

Это нормально — установщик **не имеет цифровой подписи**.

Нажмите:

1. **Дополнительные сведения**  
2. **Выполнить в любом случае**

Установщик автоматически выполнит:

- копирование файлов Randomizer  
- установку Python 3 (если отсутствует)  
- установку нужных модулей  
- запрос вашей **IWBTB ZIP**  
- распаковку в `/IWBTB`  
- создание ярлыков в меню Пуск  

---

### ▶ Шаг 2 — Запуск Randomizer

Запуск:

**Пуск → Boshy Randomizer**

Проверяется:

- корректный импорт IWBTB  
- наличие Python и модулей  
- целостность файлов  

При ошибках выводится подробная диагностика.

## ▶ Начало забега

• Каждый забег начинается с **Туториала**.  
• Далее, в зависимости от настроек GUI:  
  – **Случайный маршрут**  
  – **Target Collect Mode**

## ▶ Системное поведение

• Используется только **SaveFile1**.  
• **Не удаляйте SaveFile1.**  
• SaveFile2 и SaveFile3 перезаписываются каждый раз.  
• Достижения и разблокируемые элементы сохраняются весь забег.  
• **Awesomesauce** всегда доступен в начале для гарантии получения **Gastly**.  
• Комната телепорта работает нормально, но:  
  Для прогресса необходимо **проходить уровни, заданные рандомайзером** — пропуск невозможен.

---

## 🧩 Item Randomizer — детали

IWBTB вылетает при попытке заменить предметы **внутри игры**.  
Поэтому работа модуля такая:

- ✔ **Собранные персонажи рандомизируются**  
- ✖ **Игровые предметы не заменяются** (защита от вылетов)  
- ✔ Предметы рандомизируются **только в статистике**  
- ✔ Нет риска для геймплея  
- ✔ Полностью стабильный и безопасный для маршрутизации

# 🎲 Seed‑система

<div align="left">
  <img src="../Custom/route_overlay.gif?raw=true" width="300">
</div>

Пример:

```
R14-B4-T0-C2-P1-D1-S152722-ER5-EB34C
```

означает:

- **R** – количество уровней  
- **B** – количество боссов  
- **T** – режим Target Collect (0 = выкл., 1 = вкл.)  
- **C** – рандомайзер персонажей  
  - 0 = выключен  
  - 1 = случайный персонаж в начале забега  
  - 2 = случайный персонаж на каждом уровне  
- **P** – рандомайзер предметов (0 = выкл., 1 = вкл. — персонажи рандомизируются, предметы **не** заменяются в игре для предотвращения вылетов)  
- **D** – сложность  
  - 0 = Ez  
  - 1 = Average  
  - 3 = Rage  
- **S** – сам сид  
- **ER** – маска включённых опциональных уровней  
- **EB** – маска включённых опциональных боссов  

Используя этот код, любой игрок получит **точно такой же маршрут, сложность и RNG персонажей**.
