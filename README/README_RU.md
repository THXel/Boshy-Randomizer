## Пять способов играть

| | |
| --- | --- |
| **Randomizer** | Уровни, боссы и сундуки вперемешку, а в конце — Солгрин. |
| **Target Select** | Найди нужные предметы и победи заданных боссов, чтобы добраться до Солгрина. |
| **Normal** | Пройди оригинальный маршрут с любимыми дополнительными настройками. |
| **Boss Rush** | Боссы один за другим. Состав выбираешь ты. |
| **Level Rush** | Пройди выбранные уровни и сразись с Солгрином. |

## Что ждёт за следующим выходом?

- **Новые пути по Boshy:** Перемешай уровни, боссов и секретные пути. Ты выбираешь, что включить.
- **Каждый сундук — сюрприз:** Предмет или новый персонаж? Открой и узнай.
- **Один сид. Кто быстрее?:** Поделись сидом с друзьями и соревнуйтесь на одном маршруте.
- **Место для трёх забегов:** Один для тренировки, другой для гонки, третий для хаоса. Продолжай с того места, где остановился.
- **Прогресс перед глазами:** Время, смерти и предметы в LiveTracker — в том числе для стрима.
- **Солгрин ждёт:** Доберись до финального боя и посмотри на результаты забега.

## Выбери платформу

**Windows (.exe) · Linux (.deb) — Скоро**

Нужна собственная папка Boshy или ZIP. Оригинальная игра не включена. [Скачать I Wanna Be The Boshy на Grynsoft](https://grynsoft.com/site/game/i-wanna-be-the-boshy)

Рандомайзер создаёт отдельную копию игры. Оригинальная игра и её сохранения остаются отдельно.

## Полезно знать

<details>
<summary>Можно использовать на стриме?</summary>

Да. Открой встроенный LiveTracker из игрового меню и используй его в браузере или как источник браузера в OBS.

</details>

<details>
<summary>Что делать при проблеме с переходом?</summary>

Откройте диагностику в меню игры и добавьте режим, сид и описание проблемы в сообщение на GitHub.

</details>

<details>
<summary>Кто уже тестировал randomizer?</summary>

Пока игру тестировал только THXel. Идут последние проверки перед первой финальной версией.

</details>

<details>
<summary>Когда можно будет скачать?</summary>

Первый финальный выпуск готовится. Установщик Windows и пакет Linux DEB появятся здесь после готовности. Дата выпуска пока не определена.

</details>

<details>
<summary>Есть онлайн-режим?</summary>

Это одиночный рандомайзер. Старое онлайн-меню отключено. Делись сидами, чтобы проходить сопоставимые маршруты с друзьями.

</details>
