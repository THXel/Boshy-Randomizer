## 5つの遊び方

| | |
| --- | --- |
| **Randomizer** | ステージ、ボス、宝箱をシャッフル。最後はSolgryn戦へ。 |
| **Target Select** | 指定されたアイテムを集め、ボスを倒してSolgrynを目指そう。 |
| **Normal** | オリジナルのルートに、お好みの追加設定を。 |
| **Boss Rush** | 選んだボスと次々に対戦。 |
| **Level Rush** | 選んだステージを攻略し、最後にSolgrynへ。 |

## 次の出口には何が待っている？

- **Boshyに新しい道を:** ステージ、ボス、隠しルートをシャッフル。何を入れるかは自分次第。
- **宝箱を開ける楽しみ:** アイテムか、新しいキャラクターか。開けてからのお楽しみ。
- **同じシードで競争:** シードを友達と共有して、同じルートでタイムを競おう。
- **3つのランを保存:** 練習用、競争用、カオスを楽しむ用。続きはいつでも再開できます。
- **進み具合をひと目で:** LiveTrackerでタイム、死亡回数、集めたアイテムを確認。配信にも使えます。
- **最後はSolgryn:** ラストバトルを目指し、ランの結果を振り返ろう。

## ランの進行をひと目で

タイム、死亡回数、アイテム、目標をゲームの横やOBSに表示。ゲームメニューからLiveTrackerを開けます。

![ランの進行をひと目で](../site/media/live-tracker.png)

## 見慣れたBoshyが様変わり

いつもの世界を違う背景、色、スプライトで。どこまで変えるかは自分で選べます。

プレイ中にショットを変えたり、音楽をシャッフルしたり。 オリジナルの音楽かUndertaleを選択。追加のKamilia 3・WannaFest22パックでは、それぞれの音楽と死亡演出を楽しめます。

[![Undertale：ケツイを忘れずに。](../site/media/death-undertale.gif)](https://thxel.github.io/Boshy-Randomizer/site/ja/#gallery)

[音声付き動画](https://thxel.github.io/Boshy-Randomizer/site/media/death-undertale.mp4) · [ゲームをのぞいてみよう](https://thxel.github.io/Boshy-Randomizer/site/ja/#gallery)

## 少しの助けと、少しのカオス。

ゲームメニューで練習用の補助や挑戦を変えるオプションを選べます。

アイテムのポップアップ抑制 · マウスのゴースト無効化 · 攻撃可能な各フェーズのボスHPを1に · God Mode · ボタン長押しで連射 · ミラーモード · 死亡後にキャラクター変更 · ボスイントロを自動スキップ · 宝箱演出を短縮 · 音楽をシャッフル · Sprite Chaos設定 · クモのサプライズ · 画面の揺れをオフ

## 遊びやすい設定で

マウス・キーボード対応 · F4でウィンドウ・全画面切替 · 従来の4:3・引き伸ばし16:9 · 5言語対応

## プラットフォームを選択

**Windows (.exe) · Linux (.deb) — 近日公開**

自分のBoshyフォルダーまたはZIPが必要です。ゲーム本体は含まれません。 [GrynsoftでI Wanna Be The Boshyをダウンロード](https://grynsoft.com/site/game/i-wanna-be-the-boshy)

ランダマイザーは専用のゲームコピーを作成します。元のゲームとセーブデータは別に保たれます。

## 知っておきたいこと

<details>
<summary>配信にも使えますか？</summary>

はい。ゲームメニューから内蔵LiveTrackerを開き、ブラウザーやOBSのブラウザーソースで使えます。

</details>

<details>
<summary>遷移がおかしいときは？</summary>

ゲームメニューの診断を開き、モード、シード、問題の説明をGitHubの報告に添えてください。

</details>

</details>

<details>
<summary>いつダウンロードできますか？</summary>

初の正式版を準備中です。完成後、WindowsインストーラーとLinux DEBをここで公開します。公開日はまだ決まっていません。

</details>

</details>
