--------------------------------------------------------------
ABOUT
--------------------------------------------------------------
This program is a fan-made randomizer created for the game
"I Wanna Be The Boshy" by Solgryn (Grynsoft).

It randomizes certain aspects of the game for fun and speedrunning
purposes. This is NOT the original game, only the randomizer tool.

--------------------------------------------------------------
IMPORTANT NOTICE
--------------------------------------------------------------
To use this randomizer, you must manually add the original game
"I Wanna Be The Boshy" (by Solgryn) into the folder:
    \IWBTB\I Wanna Be The Boshy.exe

The original game can be downloaded for free from:
    https://grynsoft.com/old-games

This randomizer was developed using Python and various open-source
Python libraries.
