Современный рандомайзер для "I Wanna Be The Boshy"
Случайные маршруты • Seed-коды • ER/EB маски • Live Tracker

--------------------------------------------------------------
ОСОБЕННОСТИ
--------------------------------------------------------------
• Случайный порядок уровней и боссов (полностью детерминированно)
• Target Collect Mode – скрытый маршрут, цели по seed
• Character Randomizer – случайный старт или каждый уровень
• Item Randomizer – безопасный режим (только статистика)
• Live Tracker – предметы, боссы, достижения, персонажи и таргеты
• Конечная статистика + код маршрута
• Seed-Lock – при вводе seed настройки автоматически фиксируются
• Автоматическая установка и импорт игры

--------------------------------------------------------------
ТРЕБОВАНИЯ
--------------------------------------------------------------
• Windows 10 или новее
• Интернет при первой установке
• Оригинальный ZIP IWBTB (Grynsoft)

--------------------------------------------------------------
УСТАНОВКА
--------------------------------------------------------------
1) Скачать установщик:
   https://github.com/THXel/Boshy-Randomizer/raw/refs/heads/Boshy-Randomizer/Boshy%20Randomizer%20installer.exe

2) Запустить файл:
      Boshy Randomizer Installer.exe

   Важно: SmartScreen может предупредить.
   Выберите:
      «Дополнительные параметры» → «Выполнить в любом случае»

3) Установщик выполнит автоматически:
   • установку Python (если отсутствует)
   • установку модулей
   • установку шрифта Its-Boshy-Time
   • импорт IWBTB ZIP → папка /IWBTB
   • создание ярлыков

4) Запуск:
      Пуск → Boshy Randomizer

--------------------------------------------------------------
ГЕЙМПЛЕЙ И РЕЖИМЫ
--------------------------------------------------------------

НАЧАЛО ЗАБЕГА
• Каждый забег начинается в Tutorial.
• Далее:
     - Random Route Mode
     - Target Collect Mode

ПОВЕДЕНИЕ СИСТЕМЫ
• Используется только SaveFile1 (НЕ удалять).
• SaveFile2/3 всегда перезаписываются.
• Достижения/разблокировки сохраняются на весь забег.
• Awesomesauce всегда доступен в начале (гарантия Gastly).
• Телепорт работает, но пропускать уровни нельзя — только маршрут рандомайзера.

--------------------------------------------------------------
CHARACTER RANDOMIZER
--------------------------------------------------------------
• Dark Boshy по умолчанию
• Опции:
     - случайный при старте
     - случайный на каждом уровне
• При включении: меню F3 заблокировано.

--------------------------------------------------------------
ITEM RANDOMIZER (БЕЗОПАСНЫЙ РЕЖИМ)
--------------------------------------------------------------
• Игра вылетает при замене предметов в геймплее.
• Поэтому:
     ✔ рандомизируются только собранные персонажи
     ✔ предметы остаются оригинальными
     ✔ рандомизация предметов — только в статистике
• Абсолютно безопасно для прохождения.

--------------------------------------------------------------
TARGET COLLECT MODE
--------------------------------------------------------------
• Маршрут скрыт
• Цели выбираются из seed
• Соберите все цели → Solgryn появляется автоматически

Можно отключать только:
• Boberman
• ?
• Ridley

Все остальные зоны должны быть включены.

--------------------------------------------------------------
LIVE TRACKER
--------------------------------------------------------------
Отслеживает:
• предметы
• достижения
• боссов
• персонажей
• прогресс
• В Target Mode: обязательные Target Items

Полностью автоматический.

--------------------------------------------------------------
SEED-СИСТЕМА
--------------------------------------------------------------
Пример:
   R14-B4-T0-C2-P1-S152722-ER5-EB34C

Обозначения:
• R  – количество уровней
• B  – количество боссов
• T  – Target Mode (0/1)
• C  – режим случайного персонажа
• P  – режим Item Randomizer
• S  – seed
• ER – маска включённых уровней
• EB – маска включённых боссов

Используя этот код, можно полностью повторить забег.
