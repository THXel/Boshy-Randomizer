"I Wanna Be The Boshy" 用モダンランダマイザー
ランダムルート • Seedコード • ER/EBマスク • ライブトラッカー

--------------------------------------------------------------
特徴
--------------------------------------------------------------
• レベルとボスの順番を完全シード制でランダム化
• Target Collect Mode – ルート非表示、Seedに基づくターゲット
• Character Randomizer – ラン開始時またはステージごとにランダム
• Item Randomizer – セーフステータスモード（クラッシュ防止）
• ライブトラッカー – アイテム、ボス、実績、キャラ、ターゲット表示
• エンドスクリーンに統計 + ルートコード
• Seed-Lock – Seed入力でGUI設定が自動的に適用
• 自動セットアップ & IWBTBインポート

--------------------------------------------------------------
必要環境
--------------------------------------------------------------
• Windows 10 以降  
• 初回セットアップ時にインターネット接続  
• IWBTB のオリジナルZIP（Grynsoft）

--------------------------------------------------------------
インストール
--------------------------------------------------------------
1) インストーラーをダウンロード:
   https://github.com/THXel/Boshy-Randomizer/raw/refs/heads/Boshy-Randomizer/Boshy%20Randomizer%20installer.exe

2) 実行:
      Boshy Randomizer Installer.exe

   注意: SmartScreen が警告を表示する場合があります。
   「詳細情報」 → 「実行する」を選択してください。

3) インストーラーは自動的に以下を実行します:
   • Randomizerファイルをコピー  
   • Python 3 をインストール（必要なら）  
   • 必要なモジュールをインストール  
   • 「It’s-Boshy-Time」フォントを追加  
   • IWBTB ZIP を /IWBTB に展開  
   • スタートメニューにショートカット作成  

4) 起動:
      スタートメニュー → Boshy Randomizer

--------------------------------------------------------------
ゲームプレイ & モード
--------------------------------------------------------------

RUN開始
• すべてのRunはチュートリアルから始まります。  
• その後GUI設定に応じて:
     - ランダムルートモード  
     - ターゲットコレクトモード

システム動作
• SaveFile1 のみ使用されます。  
• SaveFile1 を削除しないでください。  
• SaveFile2/3 は毎回リセットされます。  
• 実績・アンロックはRun全体で保持されます。  
• Awesomesauce は Run開始時に必ず所持 → Gastly を確実に入手可能。  
• テレポートルームは動作しますが：
     Randomizer が指定したステージを必ずプレイしてください。
     スキップはできません。

--------------------------------------------------------------
キャラクターランダマイザー
--------------------------------------------------------------
• デフォルト: Dark Boshy  
• オプション:
     - Run開始時にランダム  
     - ステージごとにランダム  
• 有効時:
     F3 キャラクターメニューは無効化（Seed再現性のため）

--------------------------------------------------------------
アイテムランダマイザー（安全モード）
--------------------------------------------------------------
• ゲーム内アイテムの置き換えはクラッシュの原因になります。  
• そのため仕様は次の通り:
     ✔ 取得したキャラクターのみランダム化  
     ✔ ゲーム内アイテムは変更されない  
     ✔ ランダム化はステータス画面にのみ表示  
• 非常に安定しており、ルーティングに完全対応。

--------------------------------------------------------------
ターゲットコレクトモード
--------------------------------------------------------------
• ルート非表示  
• Seedによりターゲット決定  
• 全ターゲット取得後 → Solgryn が自動出現

無効化できるのは以下のみ:
• Boberman  
• ?  
• Ridley  

その他のエリアは必ず有効にする必要があります。

--------------------------------------------------------------
ライブトラッカー
--------------------------------------------------------------
リアルタイムで追跡:
• アイテム  
• 実績  
• ボス  
• キャラクター  
• 進行状況  
• Target Collect Modeではターゲットアイテムも表示

完全自動で動作します。

--------------------------------------------------------------
Seedシステム
--------------------------------------------------------------
例:
   R14-B4-T0-C2-P1-S152722-ER5-EB34C

意味:
• R  – レベル数  
• B  – ボス数  
• T  – ターゲットモード  
• C  – キャラクターランダムモード  
• P  – アイテムランダムモード  
• S  – Seed値  
• ER – レベルマスク  
• EB – ボスマスク  

このSeedを使えば、誰でも同じRunを完全再現できます。
